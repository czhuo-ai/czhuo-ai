## 两个能跑起来的项目

### [rag-kb](https://github.com/czhuo-ai/rag-kb) · 企业知识库问答（RAG 全链路）

把一批中文文档（Markdown / Word / PDF）切分、向量化、建索引，回答问题并给出可核对的引用；资料里没有的就直接说没有。

| 指标 | 数值 |
| --- | --- |
| 语料 / 片段 | 16 个文档 / 270 个片段 |
| 评测集 | 38 题（30 可答 + 8 不可答） |
| 召回 recall@5 | **96.7%** |
| MRR@10 | **86.7%** |
| 不可答题拒答 | **8 / 8** |
| 延迟（top_k=3） | P50 0.60 s / P95 1.59 s |

三种切分策略在同一套题上对比过：标题切分 > 固定长度 > 语义切分；模型重排多花 1 秒但没有提升，所以关掉了。这些负结果也写在 README 里。

`Python` `FastAPI` `SQLite` `BM25 + 向量混合检索` `智谱 embedding-3` `glm-4-air`

### [nl2sql-agent](https://github.com/czhuo-ai/nl2sql-agent) · 自然语言查数据

问一句话，它把问题变成只读 SQL、跑出结果、画图并用中文解释。数据是真实抓取的 119 条深圳招聘岗位。

| 指标 | 数值 |
| --- | --- |
| 评测集 | 30 题（带 gold SQL） |
| 一次通过率 | **83.3%（25 / 30）** |
| 延迟 | P50 1.67 s / P95 2.11 s |
| 首版 → 现在 | 26.7% → 83.3% |

提升主要不靠改提示词，而是补全 schema 里的取值范围、去掉有歧义的视图、数值比较加容差——失败的 5 题也逐条写在 README 里。

`Python` `FastAPI` `LangGraph` `DuckDB` `Plotly` `智谱 glm-4-air`
